# K&S SOLAR ACCOUNTS

reate a modern cloud-based accounting web application similar to Octal Accounts.
The system should be designed for small and medium businesses.

Core Features Required:

User authentication (Admin, Accountant, Sales role-based access)

Dashboard with financial summary (Total Sales, Expenses, Profit, Outstanding Receivables, Payables)

Invoice creation and management (PDF download + print option)

Customer and Supplier management

Sales and Purchase tracking

Expense management

Inventory/Stock management with stock alerts

Bank account management and transaction records

Tax calculation (GST/VAT configurable)

Financial reports (Profit & Loss, Balance Sheet, Cash Flow)

Multi-currency support

Secure cloud database storage

Design Requirements:

Modern, clean UI

Responsive (mobile + desktop)

Sidebar navigation

Professional business theme (blue/white)

Technical Requirements:

Use React (frontend)

Node.js / Express (backend)

PostgreSQL or Firebase database

JWT authentication

API-based architecture

Add sample dummy data for demo purposes.
